Method & rendered outputs
Rich text mixing Roboto, Playfair Display, Merriweather, and Lobster (self-hosted Google Fonts). 400px width, 1× resolution, two warm-ups, median of seven fresh renders per library. Each timed DOM capture uses a new root element and fresh content parsed from HTML; render-tag parses that same HTML internally. SnapDOM uses invalidate: true and cache: false to disable capture memoization and persistent library caches. Modern-screenshot and html2canvas use new contexts; dom-to-image-more resets per-render resource state and disables cached default-style copying. Font and module loading are excluded. Browser font, glyph, and HTTP caches are not disabled; work may be cached within a single call. Each render includes a pixel readback, and any font embedding inside the call is timed. Libraries have different goals: rich text drawing versus DOM capture. Compare output quality as well as speed.

USAGE
Core API.
Render directly, use measurements in your design,
or measure text in a headless workflow.

      

      

        
import { render } from 'render-tag';

// Load the fonts your content uses before rendering.
await Promise.all([
  document.fonts.load('400 24px "Roboto"'),
  document.fonts.load('700 24px "Roboto"'),
]);

const { canvas, height } = render({
  html: '<p style="font-family:Roboto;font-size:24px">Hello <b>world</b></p>',
  width: 400,
});

document.body.appendChild(canvas);

        
import { layout, drawLayout } from 'render-tag';

const result = layout({
  html: '<p>Hello <b>world</b></p>',
  width: 280,
});

// Use measurements to check whether text fits your design.
const fits = result.height <= 200;

// Boxes expose lineBoxes; text runs carry positions and styles.
console.log(result.layoutRoot);

// Paint the measured text when you need a preview.
const { canvas } = drawLayout({ layout: result, width: 280 });

        
import { layout, setDOMParser } from 'render-tag';
import { DOMParser } from 'linkedom';
import { createCanvas } from '@napi-rs/canvas';

// Your application supplies these two adapters.
setDOMParser(new DOMParser());
const ctx = createCanvas(1, 1).getContext('2d');

// Register your fonts before measuring. No drawing or DOM layout.
const result = layout({ html: '<p>Measure this text.</p>', width: 400, ctx });
console.log(result.height);
console.log(result.layoutRoot);

      

      
Load fonts first. These functions are synchronous. Recompute layout when content, styles, width or fonts change.

      
render() measures and draws.
layout() returns geometry without painting.
drawLayout() paints an existing layout.
